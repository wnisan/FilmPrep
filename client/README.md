# FilmPrep Client

React + Vite (JavaScript).

## Запуск

```bash
cd client
npm run dev
```

Откроется http://localhost:5173  
Запросы `/api/*` проксируются на Express (`localhost:4000`).

## Сейчас

Лендинг FilmPrep + проверка health API. Маршруты `/login`, `/register`, `/catalog` — заглушки (страницы появятся позже).
