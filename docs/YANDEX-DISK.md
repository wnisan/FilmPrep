# Видео на Яндекс Диске

FilmPrep умеет:

- **хранить нарезанное видео (HLS) на вашем Яндекс Диске** — бесплатно, в пределах места на Диске;
- **брать исходные фильмы прямо с Диска** — из списка ваших видео или по публичной ссылке
  (`https://disk.yandex.ru/d/…`). Сервер сам скачивает файл, браузер ничего не загружает.

Импорт по публичной ссылке работает сразу, без настройки. Для хранения видео на Диске
и выбора файлов из списка нужен OAuth-токен.

## Как получить токен (5 минут)

1. Откройте <https://oauth.yandex.ru/client/new> и войдите в свой аккаунт Яндекса.
2. Название — `FilmPrep`. Платформа — **«Веб-сервисы»**,
   Redirect URI — `https://oauth.yandex.ru/verification_code`.
3. В доступах найдите **«Яндекс.Диск REST API»** и отметьте:
   - «Чтение всего Диска» (`cloud_api:disk.read`),
   - «Запись в любом месте на Диске» (`cloud_api:disk.write`),
   - «Доступ к информации о Диске» (`cloud_api:disk.info`).
4. Создайте приложение и скопируйте **ClientID**.
5. Откройте в браузере (подставьте свой ClientID):
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID`
   и нажмите «Разрешить». Появится токен — это длинная строка вида `y0_AgAAAA…`.
6. Добавьте в `server/.env`:

   ```env
   YADISK_TOKEN=y0_AgAAAA...
   # папка, куда складывается нарезанное видео (создастся сама)
   YADISK_ROOT=disk:/FilmPrep
   ```

7. Перезапустите сайт: `stop.bat`, затем `start.bat`
   (или `docker compose up -d --build api`).

В админке на вкладке «Видео» появится «Хранилище: Яндекс Диск» и кнопка
«Выбрать из моих видео на Диске».

Токен живёт год. Не публикуйте его и не коммитьте `.env` в git.

## Как это работает

- Новые фильмы после нарезки попадают в `disk:/FilmPrep/hls/<id фильма>/…`.
  Уже загруженные раньше фильмы остаются там, где были (для каждого фильма запоминается его хранилище).
- Перенести старые фильмы из локальной папки на Диск: `cd server && npm run storage:migrate`.
- Плеер получает видео через API: сервер берёт сегменты с Диска и отдаёт их браузеру.
  Ссылки на скачивание кэшируются на 20 минут, чтобы не упираться в лимиты API Диска.
- Если нужно хранить видео локально, а с Диска только импортировать исходники,
  добавьте `STORAGE_DRIVER=local`.

## Альтернативы

Если Диска не хватит, подойдёт любое S3-совместимое хранилище (см. `VIDEO-STORAGE.md`):
Backblaze B2 — 10 ГБ бесплатно без банковской карты; Cloudflare R2 — 10 ГБ и бесплатный трафик.
