# Видео: HLS-стриминг и облачное хранилище

## Как это устроено

```
Админ загружает .mp4/.mkv/.mov
        │  (XHR с прогрессом)
        ▼
server/uploads/tmp  ──ffmpeg──►  HLS: master.m3u8 + 720p/ + 360p/ (сегменты по 6 с)
                                        │
                                        ▼
                     Хранилище (S3-совместимое облако или локальная папка)
                                        │   в БД: video_storage_key = hls/<id>/<ts>/master.m3u8
                                        ▼
Плеер (hls.js) ◄── /api/v1/stream/<id>/<подписанный токен>/master.m3u8
```

- **Нарезка в HLS** — как у Netflix/Кинопоиска: видео режется на короткие сегменты
  в нескольких качествах, плеер сам выбирает качество под скорость интернета.
  ffmpeg ставится npm-пакетом `ffmpeg-static`, отдельно ничего устанавливать не нужно.
- **Подписанная ссылка**: токен в пути действует 8 часов (`STREAM_TOKEN_TTL`) и привязан
  к фильму — ссылку нельзя «расшарить» навсегда.
- **Исходник удаляется** после нарезки — на сервере ничего не остаётся.
- **Субтитры** (EN для анализа и плеера, RU для плеера) — маленькие текстовые файлы,
  хранятся на сервере; русские можно загрузить или перевести нейросетью в админке.

## Бесплатное облако: Backblaze B2 (10 ГБ, без банковской карты)

1. Зарегистрируйтесь: <https://www.backblaze.com/sign-up/cloud-storage> (только email).
2. **Buckets → Create a Bucket**
   - Bucket Unique Name: например `filmprep-video-ulian`
   - Files in Bucket: **Private** (приватный — видео отдаёт наш сервер)
   - Остальное по умолчанию → Create.
   - На карточке бакета посмотрите **Endpoint**, например `s3.us-west-004.backblazeb2.com`.
3. **Application Keys → Add a New Application Key**
   - Name: `filmprep`, Allow access to Bucket: ваш бакет, Type: **Read and Write**.
   - Скопируйте `keyID` и `applicationKey` (второй показывается один раз).
4. Впишите в `server/.env`:

   ```env
   S3_ENDPOINT=https://s3.us-west-004.backblazeb2.com
   S3_REGION=us-west-004
   S3_BUCKET=filmprep-video-ulian
   S3_ACCESS_KEY_ID=<keyID>
   S3_SECRET_ACCESS_KEY=<applicationKey>
   S3_LABEL=Backblaze B2
   ```

   `S3_REGION` — часть endpoint между `s3.` и `.backblazeb2.com`.
5. Проверка и перенос уже нарезанных фильмов из локальной папки в облако:

   ```bash
   cd server
   npm run storage:check     # запись/чтение/удаление тестового файла
   npm run storage:migrate   # перенос готовых HLS в облако
   ```

6. Перезапустите сервер — в админке на вкладке «Видео» появится «Хранилище: Backblaze B2».

**Лимиты бесплатного тарифа B2:** 10 ГБ хранения, скачивание бесплатно до 3× объёма
хранения в месяц, 2 500 запросов на чтение в сутки (≈ 20 просмотров короткометражки
целиком). С запасом для демо-контента. Демо-фильмы занимают ~1,5 ГБ.

### Другие S3-совместимые варианты

| Сервис | Бесплатно | Особенности |
|---|---|---|
| Cloudflare R2 | 10 ГБ, трафик бесплатный | нужна банковская карта |
| Yandex Object Storage | 1 ГБ | оплата российской картой |
| MinIO в Docker | без ограничений | хранится на своём компьютере |

Код не зависит от провайдера: меняются только `S3_*` в `.env`.

## Режимы отдачи сегментов (`STREAM_SEGMENTS`)

- `proxy` (по умолчанию) — плейлисты и сегменты идут через API. Работает с приватным
  бакетом и не требует настройки CORS.
- `signed` — API отдаёт плейлист, в котором сегменты заменены на временные
  подписанные ссылки прямо в бакет (разгружает сервер, как CDN). Нужно включить CORS
  в настройках бакета (B2: Bucket Settings → CORS Rules → «Share everything … with all origins»).

## Плеер

- Качество: «Авто» или вручную (720p / 360p).
- Субтитры: выключены / English / Русский / **English + русский одновременно**.
- Продолжение с места остановки, скорость 0.75–1.5×, полный экран.
- Горячие клавиши: `Пробел`/`K` — пауза, `←`/`→` — 5 с, `↑`/`↓` — громкость,
  `F` — полный экран, `M` — звук, `C` — режим субтитров, `R` — повторить реплику.
