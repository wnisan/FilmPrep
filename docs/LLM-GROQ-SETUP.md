# Подключение бесплатной «нейронки» через Groq API

Документ для FilmPrep: как получить ключ, куда его вписать, что он будет делать в проекте, и подходит ли это для демо/пет-проекта.

> Если ты имела в виду не **Groq**, а **Grok (xAI)** или **Gemini** — в конце есть короткие альтернативы. Для FilmPrep лучше всего именно **Groq**.

---

## 1. Будет ли Groq нормален здесь?

**Да — как усиление NLP, не как замена всего модуля.**

| Задача FilmPrep | Без ключа (сейчас) | С Groq |
|-----------------|--------------------|--------|
| Парсинг субтитров `.srt` | ✅ локально | ✅ локально |
| Частотный словарь | ✅ локально | ✅ локально |
| Русские переводы слов/фраз | ❌ часто пусто | ✅ через LLM |
| Пояснения к грамматике | ✅ шаблоны | ✅ можно улучшить текстом LLM |
| Вопросы теста | ✅ вручную админом | ✅ можно генерировать (опционально) |

**Рекомендуемая схема для защиты:**
1. Локальный `ml-module` как и сейчас извлекает кандидатов (слова/фразы/грамматику).
2. Если в `.env` есть `GROQ_API_KEY` и `LLM_ENABLED=true` — LLM **обогащает** результат (переводы, короткие определения).
3. Если ключа нет — приложение всё равно работает (как сейчас).

Так ты честно говоришь на защите: «есть отдельный NLP-модуль; нейросетевое обогащение через Groq API опционально».

**Плюсы Groq для тебя:**
- есть бесплатный тариф (Free)
- API совместим с OpenAI-форматом → просто подключать из Node.js
- быстро отвечает
- для небольших объёмов (1–5 фильмов, обработка субтитров) лимитов обычно хватает

**Минусы:**
- нужен интернет при обработке
- лимиты Free (RPM/RPD) — не гонять огромные файлы пачками
- ключ нельзя светить в GitHub
- для защиты лучше иметь fallback без ключа (у нас уже есть)

## 2. Что сделать тебе по шагам (получить ключ)

### Шаг 1. Регистрация
1. Открой: https://console.groq.com  
2. Зарегистрируйся (Google/GitHub/email).  
3. Подтверди аккаунт, если попросят.

### Шаг 2. Создай API Key
1. Открой: https://console.groq.com/keys  
2. Нажми **Create API Key**.  
3. Дай имя, например: `filmprep-local`.  
4. Скопируй ключ сразу (потом его часто не показывают полностью).  
5. Сохрани в надёжном месте (блокнот/менеджер паролей), **не в чат публично и не в git**.

### Шаг 3. Проверь, что ключ живой (в PowerShell)
Подставь свой ключ вместо `gsk_...`:

```powershell
$env:GROQ_API_KEY = "gsk_твой_ключ_сюда"

curl.exe https://api.groq.com/openai/v1/chat/completions `
  -H "Authorization: Bearer $env:GROQ_API_KEY" `
  -H "Content-Type: application/json" `
  -d "{\"model\":\"llama-3.3-70b-versatile\",\"messages\":[{\"role\":\"user\",\"content\":\"Say hi in one word\"}]}"
```

Если в ответе есть `"content"` — ключ работает.

Документация: https://console.groq.com/docs/quickstart

## 3. Куда вписать ключ в FilmPrep

### Шаг 4. Открой `server/.env`
Добавь (или дополни):

```env
# --- LLM / Groq (опционально) ---
LLM_ENABLED=true
LLM_PROVIDER=groq
GROQ_API_KEY=gsk_твой_ключ_сюда
LLM_MODEL=llama-3.3-70b-versatile
LLM_BASE_URL=https://api.groq.com/openai/v1
```

### Шаг 5. Проверь `.env.example` (без секрета)
В репозитории должен быть только шаблон:

```env
# LLM_ENABLED=false
# LLM_PROVIDER=groq
# GROQ_API_KEY=
# LLM_MODEL=llama-3.3-70b-versatile
# LLM_BASE_URL=https://api.groq.com/openai/v1
```

### Шаг 6. Убедись, что `.env` в `.gitignore`
У нас уже игнорируется `.env` — ключ в git не уйдёт.

### Шаг 7. Перезапусти API
```bash
cd server
npm run dev
```

Пока код обогащения через Groq может быть ещё не включён в пайплайн — тогда ключ просто «готов».  
Подключение в код = отдельный небольшой шаг (сказать ассистенту: «подключи Groq к NLP»).

## 4. Как это будет работать в приложении (логика)

```
Админ загружает .srt
   → локальный ml-module парсит и собирает словарь/фразы/грамматику
   → если LLM_ENABLED=true и есть GROQ_API_KEY:
        для топ-N слов/фраз запрос в Groq:
        «дай краткий перевод на русский + 1 пример»
   → результат пишется в PostgreSQL (definition_ru / translation_ru)
   → learner видит уже обогащённые материалы
```

**Важно:** не отправляй весь фильм целиком одним гигантским промптом.  
Отправляй пачками (например по 20–30 слов) — так стабильнее на Free.

## 5. Модель: какую выбрать

Для FilmPrep сейчас разумно:
- `llama-3.3-70b-versatile` — качественно, норм для переводов/объяснений  
или более лёгкую/быструю из актуального списка: https://console.groq.com/docs/models

Если модель устарела/удалена — Groq вернёт ошибку; тогда просто поменяй `LLM_MODEL` в `.env`.

---

## 6. Лимиты Free — хватит ли

Для демо/защиты обычно хватает:
- обработать 2–5 фильмов
- обогатить словарь/фразы

Не хватит, если:
- гонять огромные субтитры на тысячах реплик без пачек
- делать это десятки раз подряд в цикле

Смотри лимиты в кабинете: https://console.groq.com/docs/rate-limits

## 8. Безопасность (обязательно)

- [ ] Ключ только в `server/.env`
- [ ] Не кидать ключ в Discord/Telegram/скрин сдачи
- [ ] Не коммитить `.env`
- [ ] Если ключ светился — удали его в console.groq.com/keys и создай новый
- [ ] Для защиты можно временно выключить: `LLM_ENABLED=false`

## 9. Альтернативы, если не Groq

### Google Gemini (тоже часто бесплатный Free tier)
1. https://aistudio.google.com/apikey  
2. Создать API key  
3. В `.env`:
```env
LLM_PROVIDER=gemini
GEMINI_API_KEY=...
LLM_MODEL=gemini-2.0-flash
```
Нужен другой код клиента (не OpenAI-совместимый 1-в-1).

### Grok (xAI)
Платный/ограниченный, обычно менее удобен, чем Groq.

### OpenAI
Надёжно, но почти всегда платно с карты.

**Вывод:** для FilmPrep бери **Groq**.
